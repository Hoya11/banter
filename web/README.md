# banter 음성 대화 화면

두 AI의 대화를 듣다가 참여하는 화면입니다. 별도 빌드 없이 `index.html`을 FastAPI가 제공합니다.
실행 방법은 프로젝트 [README](../README.md)를 참고하세요.

## 화면의 기준

음성 대화에서는 대사 대신 현재 말하는 AI와 내 마이크 상태를 보여줍니다. 서버의 응답 생성
이벤트만으로 화자를 강조하지 않습니다. 실제 브라우저 오디오 재생이 시작된 경우에만 해당
참여자의 테두리, 상태 문구와 움직임을 켭니다. 움직임은 재생 상태 표시이며 실제 음량 파형은
아닙니다. 운영체제의 동작 줄이기 설정에서는 움직이지 않습니다.

대화 종료 이벤트 이후에도 마지막 오디오가 남아 있으면 재생과 화자 표시를 유지합니다.
끼어들기, 재생 종료와 다시 시작할 때는 실제 재생 상태에 맞춰 표시를 갱신합니다.

마이크 준비, 감지 대기, 발화, 음성 확인 중을 구분합니다. VAD는 마이크 시작이 끝난 뒤에만
AI 대화를 시작하고 청취 준비 상태를 표시합니다. 준비 중 취소하거나 마이크 권한이 거부되면
AI 세션을 시작하지 않습니다. PTT는 실제 녹음이 시작된 뒤에 녹음 중으로 표시합니다. 이전 요청의
늦은 권한 응답이나 종료 콜백은 새 입력의 표시를 바꾸지 않습니다.

텍스트 입력은 필요할 때 `텍스트로 참여`를 펼쳐 사용합니다. 음성 모드에서는 입력창에 자동으로
초점을 주지 않아 대화 시작 시 모바일 키보드가 먼저 열리지 않습니다. 음성 출력이 없는 모드나
오디오 재생에 실패한 경우에는 대화 기록을 열어 답변을 확인할 수 있습니다.

## 조작과 접근성

- VAD: `대화 시작`을 누르면 마이크를 준비한 뒤 자동 감지를 시작합니다. 대화 중 마이크
  버튼으로 끄거나 다시 켭니다. 준비 중에는 `준비 취소`로 중단할 수 있습니다.
- PTT: 버튼을 누른 동안 녹음하고 놓으면 전송합니다. 버튼에 초점을 둔 상태에서 Space 또는
  Enter를 누르고 있어도 같습니다. 초점을 잃으면 녹음을 마무리합니다.
- 텍스트 입력과 버튼에 접근 가능한 이름을 제공하며 마이크와 오류 안내를 상태 문구로 전달합니다.
- 작은 화면에서는 세로로 스크롤할 수 있고 주요 버튼과 입력창은 가로로 넘치지 않습니다.

## 검증

```bash
npm ci --ignore-scripts
npm test
```

자동 테스트는 가짜 공급자, 오디오와 VAD 이벤트로 화자 표시, 준비와 청취 구분, 키보드 조작,
늦은 이벤트와 오류 복구를 검증합니다. 2026-09-08 로컬 Chrome 화면 확인은 데스크톱과
390 px, 320 px 너비에서 진행했습니다. 브라우저 오디오 재생 상태를 사용하되 마이크 준비와
서버 및 VAD 이벤트는 가짜 입력으로 분리했습니다. 실제 마이크와 외부 음성 API는 사용하지
않았습니다. 실사용 음성 품질이나 반응 속도 측정은 아닙니다.

전사 실패나 시간 초과가 이미 끝난 발화에 도착해도 다음 발화 후보를 지우지 않습니다.
아직 말하는 중에 취소한 경우에는 침묵을 기다려 같은 발화를 곧바로 재전송하지 않습니다.

모델 정보는 [VAD 실험](../docs/experiments/vad-interruption.md), 녹음 파일의 설정 비교는
[녹음 평가 도구](../docs/experiments/vad-recording-evaluation.md)에 있습니다.
