# 트러블슈팅 기록

> 실사용에서 제기된 문제 → 진단 → 개선의 히스토리.
> 실측·재현으로 원인을 좁힌 과정을 남긴다 (증상만 보고 고치지 않는다).

## 1. 대화가 끝나지 않고 무한히 이어짐
- **증상**: AI 둘이 멈추지 않고 계속 대화 — 비용·피로 누적
- **진단**: 라디오 모드는 의도된 기획이나, PRD가 예정한 세션 캡이 미구현 상태
- **개선**: max_turns 도달 시 마무리 인사 후 종료(`done`), FE 입력 비활성
- **결과**: 세션 경계 확보. 캡이 barge보다 우선하는 규칙도 이후 검수에서 보강

## 2. 말하는 중간에 채팅을 쳐도 대화가 안 끊김
- **증상**: AI 발화 중 입력해도 무시되고 발화가 끝까지 진행
- **진단**: 발화 스트리밍 도중에는 서버가 유저 입력을 수신하지 않는 구조
- **개선**: 스트림 task와 수신 task를 동시 대기(asyncio FIRST_COMPLETED) — 유저가
  먼저 오면 스트림 취소 + 끊긴 지점까지만 기록(§2.1)
- **결과**: 텍스트 barge-in 동작. `—(끊김)` 표시로 실사용 확인

## 3. 채팅이 먼저 쌓이고 목소리가 뒤늦게 따라 읽음
- **증상**: 텍스트는 즉시, 소리는 수 초 뒤 — "말하는 주체가 목소리 나오기 전에 다음 채팅이 올라옴"
- **진단**: 텍스트(LLM 속도)와 음성(TTS+재생 속도)의 시간축 분리. 서버가 재생 상태를
  모르고 앞서 달림
- **개선**: 음성 동기 모드 — 자막은 오디오 재생 시점에 표시, FE의 played ack(seq 장부)을
  받아야 다음 턴 진행. "소리가 페이스메이커"
- **결과**: 어긋남 구조적 제거. seq 장부는 ack 유실·중복에도 안전(멱등)

## 4. 소리가 아예 안 남
- **증상**: 자막만 뜨고 전 세션 무음 (특히 말 안 걸고 듣기만 할 때)
- **진단 1**: WS 프로토콜 변경 후 브라우저가 옛 FE를 캐시 — audio 이벤트 처리 코드 부재
- **진단 2**: unlock이 전송 버튼에만 걸려, 라디오 첫 오디오가 제스처 전 도착 →
  autoplay 차단을 조용히 스킵
- **개선**: index에 Cache-Control: no-store / 첫 화면 탭·키 입력에서 unlock +
  차단 시 큐 보존·"탭해서 소리 켜기" 안내
- **결과**: 청취 전용 사용도 정상. 프로토콜 변경이 캐시로 조용히 깨지는 경로 차단

## 5. AI끼리는 빠른데 발화 사이가 너무 느림 (~8초)
- **증상**: 발화 하나 끝나고 다음 목소리까지 오랜 공백
- **진단**: 재생 종료 후에야 다음 턴(화자선정→생성→합성)을 시작하는 직렬 구조
- **개선**: prefetch(§3.2) — 재생되는 동안 다음 AI 턴을 백그라운드 완성, 유저 개입 시 폐기
- **결과**: 발화 간 평균 2.1s(실측, 유저 틈 1.5s 포함) — [latency.md](experiments/latency.md)

## 6. 내가 말하면 응답이 유독 느림 (5~8초)
- **증상**: AI끼리는 빠른데 정작 내 말에는 한참 뒤 반응
- **진단**: 유저 발화는 예측 불가라 prefetch 무효 + 발화 전체를 합성해야 첫 소리
- **개선**: Phase 3a 문장 단위 TTS — 첫 문장 완성 즉시 합성·재생, 나머지는 재생 중 준비
- **결과**: say→첫 오디오 ~2.4s(실측). 잔여 격차는 3b(스트리밍 STT) 몫

## 7. STT가 말하지도 않은 문장을 뱉음
- **증상**: `[stt] 전사: '친구들과 나누는 한국어 반말 수다...'` — 도메인 힌트 문장이 그대로 출력
- **진단**: 짧거나 조용한 오디오에서 전사 모델이 prompt 힌트를 환각으로 복창하는 알려진 부작용
- **개선**: prompt 힌트 제거 + 최소 녹음 길이 필터(서버 6KB/FE 8KB) + 전사 로그로 관측
- **결과**: 환각 입력 차단. 인식률은 신형 모델(gpt-4o-mini-transcribe)로 보강

## 8. 마이크로 말해도 내 발화가 대화에 묻힘
- **증상**: 녹음→전사되는 사이 미리 준비된 AI 발화가 계속 나와 내 말이 뒤로 밀림
- **진단**: 서버는 유저가 말하려는 것을 전사 완료 전까지 모름 — 발화권 신호 부재
- **개선**: hold 프로토콜 — 🎤 누르는 즉시 {hold} 전송: 진행 중 발화 중단 + 전사(say)가
  올 때까지 새 턴 금지(상한 15s). 내용은 늦게 와도 발화권은 0초에 잡힘
- **결과**: 손들면 조용해지는 대화. 완전한 실시간 전달(말하는 중 전사)은 3b에서

## 9. 새로고침하면 서버가 크래시 로그를 쏟아냄
- **증상**: WebSocketDisconnect → RuntimeError('send once closed') 트레이스
- **진단**: prefetch 커밋 중 연결 끊김이 except Exception에 삼켜져 "준비 실패 폴백"으로
  오분류 → 닫힌 소켓에 재전송
- **개선**: WebSocketDisconnect는 re-raise — 폴백(준비 실패)과 종료(연결 끊김)는 다른 예외
- **결과**: 새로고침 시 조용한 세션 정리

## 10. ElevenLabs가 402 Payment Required
- **증상**: 크레딧이 있어 보이는데 모든 TTS 호출이 402
- **진단**: 응답 본문 확인 — `paid_plan_required`: Voice Library(커뮤니티) 보이스는
  무료 플랜에서 API 사용 불가. 크레딧 문제가 아니었음
- **개선**: premade 보이스 × 전 모델(v2/v3/flash) 무료임을 실측 확인 → 청음 비교로
  쌍 프리셋 확정 — [tts-comparison.md](experiments/tts-comparison.md)
- **결과**: 무료 플랜으로 v3 한국어 음성 운용. "에러는 본문까지 읽어야 처방이 나온다"
