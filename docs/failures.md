# 실패와 개선 기록

## 1. 사전 생성 대기 중 입력 지연

- **문제:** AI 간 공백을 줄이기 위한 사전 생성 도입 후, 준비 대기 중 사용자 입력 처리 지연.
- **개선:** 입력과 사전 생성의 동시 대기, 동시 완료 시 입력 우선 처리.
- **결과:** 수정 전 신규 테스트 8개 중 7개 실패. 취소 경계 보강 후 모의 회귀 11개 통과. 실제 음성 지연 측정 전.

[재현과 수정](project-walkthrough.md#미완료-사전-생성-대기의-입력-지연) / [회귀 테스트](../server/tests/test_prefetch.py)

## 2. STT 전송 대기 중 입력 처리 지연

- **문제:** 입력 수신 경로에서 청크 전송 완료까지 대기. 외부 정리 제한 시간이 내부 종료 대기보다 짧아 연결 정리까지 취소.
- **개선:** 순차 전송 작업과 크기가 제한된 대기열 분리. 연결 종료 시간 조정과 정리 경로 보강.
- **결과:** 수정 전 실패한 입력 처리 3개, 연결 종료 8개 사례의 모의 테스트 통과.

[전송 지연과 연결 종료 복구](experiments/streaming-stt-ab.md#전송-지연과-연결-종료-복구)

## 3. 마이크 준비 전 대화 시작과 다음 발화 누락

- **문제:** 마이크 준비 전 세션 시작. 종료된 발화의 전사 오류로 다음 발화의 감지 상태까지 초기화.
- **개선:** 마이크 준비 후 대화 시작. 개별 전사 요청의 실패와 마이크 감지 상태 분리.
- **결과:** 시작 순서, 오류 후 다음 입력, 늦은 이벤트의 모의 테스트 통과. 수정 후 실환경 음성 입력 복구 테스트 미실시.

[첫 실사용 오류와 수정](experiments/vad-interruption.md#첫-실사용-오류와-수정)

## 4. 끼어들기 평가 입력 오류

- **문제:** 잘린 대사와 중단 표시 누락으로 일반 대화를 끼어들기 시나리오로 채점.
- **개선:** 기존 판정 정정. 평가 입력에 대사 절단과 중단 표시 반영.
- **결과:** 회귀 테스트 및 텍스트 시나리오 재평가 완료.

[평가 정정과 재측정](experiments/judge-scores.md)

## 5. 사전 생성 적용 후에도 남은 사용자 응답 지연

- **문제:** 새 사용자 입력에는 미리 준비한 AI 대사 재사용 불가. 전체 대사 생성과 합성 완료까지 대기.
- **개선:** 완성된 문장부터 합성·전송. 파일 전사와 비교할 스트리밍 STT를 별도 옵션으로 추가.
- **결과:** 문장별 전송 회귀 통과, 소수의 텍스트 입력 지연 관찰. 전체 음성 지연 전후 비교와 스트리밍 STT 효과 측정 전.

[지연 관찰과 측정 조건](experiments/latency.md)

## 6. STT 연결 종료 시 상세 오류 누락

- **문제:** 실제 연결에서 `4000`, `stage=configure` 오류 발생. 별도 모의 재현에서 설정 전송 예외가 앞서 받은 공급자 오류를 가리는 결함 확인.
- **개선:** 전사 목적의 연결 설정과 세션 생성 확인 적용. 실패 단계와 공급자 오류 정보 보존.
- **결과:** 연결 설정과 진단 경로의 모의 테스트 통과. 실제 원격 종료 원인 미확정, 수정 후 원격 전사 테스트 미실시.

[연결 생성 단계 재검증](experiments/vad-interruption.md#연결-생성-단계-재검증)

## 7. 생성 완료 후 재생 중단 표시 누락

- **문제:** 생성이 끝난 발화를 재생 중 끊어도 이력에는 완성된 대사로만 기록.
- **개선:** 음성 순번과 발화 ID 연결, 해당 발화의 중단 표시와 사전 생성 문맥 갱신.
- **결과:** 수정 전 신규 회귀 14개 중 7개 실패. ACK 시간 초과 경계 보강 후 모의 회귀 16개 통과. 전문은 보존하며 청취 위치 추정은 제외.

[이력 처리와 회귀](project-walkthrough.md#재생-중단의-이력-반영)
