자동 테스트는 모의 시간으로 상태 전이와 복구를 검증하며, 실제 반응 시간은 별도 측정 대상이다.
과거 측정은 당시 코드와 조건에서 얻은 소수의 로컬 관찰 기록으로, 비교 조건과 실패 표본을 함께 남겼다.
실제 공급자 비용과 분당 원가의 결과표는 아직 없다.

원본 녹음과 실행 로그는 Git에서 제외한다. 실제 API 호출 전에는 결제 상태, 지출 상한,
필요한 키와 예상 호출 범위를 확인하고, 공개 문서에는 측정 조건과 요약 결과를 남긴다.
