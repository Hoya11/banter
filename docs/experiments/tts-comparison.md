# TTS 청음 비교 (Phase 2)

Phase 2에서 TTS 후보를 직접 들어 보고 선택한 기록이다. 기준은 한국어 반말 수다 톤의 자연스러움, 두 목소리의 대비를 통한 화자 구분, 비용이었다.

아래 내용은 2026-08-25 당시 사용한 대사와 모델, 보이스, 키 및 요금제 상태에서의 관찰이다. 자연스러움과 페르소나 표현은 주관적인 청음 판단이며, 청취자 집단·블라인드 평가는 미실시. API 접근 결과는 당시 계정과 요청에 한정된 기록으로, 현재 요금제 조건과 다른 계정의 이용 가능 범위는 미확인.

## 2026-08-25 — 1차: provider 비교

| Provider | 모델/보이스 | 당시 청음 판단 |
|---|---|---|
| OpenAI TTS | tts-1, onyx/nova → ash/coral | 사용한 대사에서 한국어 발음이 어색하게 들려 당시에는 연결 경로 검증용으로 사용 |
| ElevenLabs | multilingual v2 / v3 | 사용한 대사에서 한국어가 더 자연스럽게 들려 선택 |

## 2026-08-25 — 2차: 당시 ElevenLabs API 접근 결과

- 처음 고른 Voice Library(커뮤니티) 보이스 2종은 API 호출에서 HTTP 402를 반환했다.
- 당시 402 응답 본문의 코드는 `paid_plan_required`였다. 해당 요청의 제약을 요금제 제한으로 해석했다. 다른 커뮤니티 보이스의 무료 플랜 이용 가능 여부는 미확인.
- 당시 키와 요금제 상태에서 호출해 본 premade(기본) 보이스 및 모델(v2/turbo/flash/v3) 조합은 사용 가능했다. 당시에는 무료 사용 가능한 조합으로 기록했다. 전체 보이스·모델 조합과 현재 무료 이용 가능 여부는 미검증.

## 2026-08-25 — 3차: premade 보이스 청음 (같은 대사, v2·v3 각 1회)

- 당시 접근 가능했던 보이스: 남 Adam/George/Brian/Daniel/Callum/Antoni/Liam/Will/Harry/Chris, 여 Sarah/Laura/Alice/Matilda/Jessica/Lily. Josh/Sam/Charlotte/Rachel 요청은 HTTP 402를 반환했다. 해당 보이스의 일반적인 이용 제한 사유는 미확인.
- 같은 대사를 v2와 v3에서 각 1회 청음했을 때 v3의 한국어 억양과 표현을 더 적합하다고 판단해 선택했다. 소규모 주관 청음에 따른 선택이며, 모델 전반의 한국어 품질 차이는 미검증.
- 태그 연출 입력으로 `[sighs]`, `[excited]`, `<break/>`를 시도했다. 당시 도현의 냉소와 소은의 들뜬 표현이 더 드러난다고 느꼈지만, 태그별 효과와 각 표기의 공식 지원 여부는 미검증.

## 당시 선택 (2026-08-25)

- 모델: **eleven_v3**
- 보이스는 두 화자의 대비를 함께 선택할 수 있도록 쌍 단위 프리셋으로 관리했다(D-004).
- `chris-jessica` (당시 활성): Chris(도현) + Jessica(소은)
- `liam-laura` (당시 예비): Liam(도현) + Laura(소은)
- 프리셋 전환은 `duo.yaml`의 `voice_preset` 값으로 선택하도록 구성했다.

## 당시 후속 과제

- 발화 LLM이 오디오 태그를 페르소나에 맞게 생성하도록 프롬프트 확장 (limit_sentences의 태그 오인 방지 포함)
- 스트리밍/문장 단위 TTS로 응답 지연(당시 발화 완성 후 합성) 단축
- 두 프리셋의 실대화 비교 청취 후 기본 조합 최종 확정

위 목록은 선택 당시 남겨 둔 과제다. 이후 문장 단위 TTS 구현과 초기 측정은 [지연 측정 기록](latency.md)에 따로 정리했다. 사용자가 두 화자를 정확히 구분하는지는 별도 검증하지 않았다.
